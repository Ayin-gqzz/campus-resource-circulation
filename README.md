# 低碳校园资源循环流转桌面系统

2026 年《软件构造》分组实验项目，面向华中师范大学南湖校区和桂子山校区，支持校园闲置物品发布、检索、交换与售卖。

**当前版本提供基于统一 JDBC 数据层的 Swing Demo。** 四个示例身份可以在本机体验发布、搜索、多人意向、协商、流转和互评。正式业务功能按迭代计划继续开发。

## 技术与目标

- Java 17 及以上，Swing 图形界面。
- Maven 管理依赖，SQLite + JDBC 持久化数据。
- JUnit 5 编写单元测试，补充集成测试与代码走查。
- 3 人协作，8 周完成，每 2 周交付一个迭代版本。
- 最终交付包含依赖的可执行 Jar、数据库脚本、实验报告与演示材料。

## 快速开始

本机已构建演示包时，可双击仓库根目录的 `启动校园循环.cmd`。启动器优先打开 Maven 构建的 `target/campus-resource-circulation-0.1.0-SNAPSHOT.jar`，也兼容 `target/campus-resource-circulation-buy-sell.jar`。启动器使用仓库内的 `data/demo.db`，无需解压 JAR 或修改文件关联。从 GitHub 下载源码后，先按下面的命令完成构建。

安装 JDK 17+ 和 Maven 3.9+，确保 `java`、`mvn` 可在终端使用。

```shell
mvn clean verify
java -jar target/campus-resource-circulation-0.1.0-SNAPSHOT.jar
```

如果已经下载 Jar，直接运行 `java -jar campus-resource-circulation-0.1.0-SNAPSHOT.jar` 即可。首次启动在工作目录下创建 `data/demo.db`，包含林、陈、王、周四个演示身份、17 条在架发布，以及一笔已完成的评价样例。旧演示库会自动补齐新版身份及集市样例，保留已有物品和流转结果；重复启动不会重复生成样例。也可用 `java -Dcampus.demo.db=demo-run.db -jar target/campus-resource-circulation-0.1.0-SNAPSHOT.jar` 指定独立数据库。

## 演示流程

### 发布时标记所在楼栋

从「闲置集市 → 发布物品 → 地图定位」打开校园地图。切换校区后，可以点选地图上的有色楼栋，使用「选择楼栋」下拉框，或搜索 `D05`、`南湖五栋`、`图书馆` 等。滚轮可缩放，拖动可平移。点击「一键定位」会在当前所选楼栋模拟定位，尚未选楼时则随机定位。

地图使用 Java2D 离线绘制，内置两个校区的实际道路、建筑轮廓和 WGS84 坐标，共有 46 个可选建筑，其中 36 栋为学生宿舍。定位提示中的坐标对应地图上的模拟落点，精度为演示参数。确认后，楼栋名称和编号回填到可选的「所在楼栋」字段，发布成功后可在集市详情查看。交易校区、交接地点和时间另行填写。

底图坐标和轮廓来自 OpenStreetMap，许可为 ODbL 1.0。每条地理记录保留对应的 OSM 对象编号。楼栋名称参考华中师范大学公开资料，`D05` 等编号为应用内编号。 [OpenStreetMap 许可与署名](https://www.openstreetmap.org/copyright) · [华中师大校园 GIS](https://gis.ccnu.edu.cn/) · [两校区迎新路线图](https://art.ccnu.edu.cn/info/1208/21117.htm) · [南湖校区地图](https://cs.ccnu.edu.cn/info/1056/13426.htm)

### 交易流程

1. 以默认的**陈同学**打开「闲置集市」，选中「高等数学教材」，点击「发起意向」并提交留言。
2. 切换到**林同学**，在「我的流转」中选中记录并点击「接受」。模拟线下交接后点击「确认交接完成」。
3. 林同学提交评价，再切换为陈同学提交另一方的评价。切换身份可以查看各自收到的信用评分。
4. 发布售卖或换物物品时，选择「南湖校区」或「桂子山校区」，再填写具体地点，例如「图书馆入口」。集市、意向确认和流转记录会显示完整交易地点。
5. 旧库会自动升级。旧的在架或进行中物品由发布人选中记录后点「补填交易地点」，再继续交易。已结束且没有地点的历史记录显示「未记录」。
6. 在侧栏打开「个人页面」，查看当前身份的加入日期、信用评分、评价条数、已发布物品和交易地点。加入日期按北京时间显示。演示库会添加一笔标记为「示例」的已完成交易和双方评价，各只添加一次。切换演示身份后，页面同步更新。
7. 在「我的流转」选中记录，可在右侧留言，沟通记录展示发送人和北京时间。在待处理或已接受阶段，双方都可以点「协商条件」提出新价格与地点，由另一方确认后生效。发起人可撤回，对方可拒绝。协商只修改本次流转的条件，保留原物品发布信息。完成或取消后可继续查看沟通与协商记录。
8. 「我的流转」通过「想买」「想卖」区分角色：想买显示自己提交的意向，想卖显示自己发布的物品收到的意向，包括对应已结束记录。当前分类高亮显示，列表仍按物品收纳，点击物品行展开或收起；展开后选择具体同学的记录，分别沟通、协商和处理交易。新提交意向后自动转到「想买」。
9. 预定取消、库存从无货恢复为有货后，之前提交过意向的其他同学会收到站内提醒。侧栏「消息提醒」显示未读数，消息保留时间，可标为已读或查看物品后重新申请；取消者不收自己的提醒。还有余量时取消一笔预定不会群发恢复有货提醒，普通待处理意向撤回也不会群发。
10. 发布时填写「交易时间」，格式为 `yyyy-MM-dd HH:mm`，按北京时间解释。集市、个人物品和交接详情显示约定时间；可在「协商条件」中只修改时间，由另一方同意后生效。时间须在未来，确认提案时再次检查是否已过期。详情另外保留发起时间和实际交接完成时间。
11. 在「我的流转」单击「对方」列的姓名，或选中记录后按回车，可查看对方的平均信用评分、评价条数、加入日期和加入天数。加入当天为 0 天，按北京时间跨日计算；无评价时显示「暂无评分」。

已有记录升级后，缺失的交易时间显示「待协商」，不会自动编造时间。通过双方协商补充时间后，再接受意向或确认交接。新建演示库的样例带有未来的交接时间；重启不会改写已保存的约定。

发布时可填写 1–9999 件同款库存，售价为每件单价；申请时选择数量，界面计算总价。提交意向不占库存，发布人接受后才锁定本次数量，有余量时其他意向保留；库存用尽才结束其余待处理意向。取消仅释放对应预定数量，完成只计入本次成交数量。旧发布和旧意向自动按 1 件迁移。

### 多件库存演示

1. 搜索「多件演示」，选择林同学发布的「全新笔记本」，库存 5 本，单价 5 元。
2. 陈同学申请 2 本，王同学申请 1 本；切换林同学，在对应分组中分别接受两条申请。
3. 此时显示「剩余 2 件 · 已预定 3 件 · 已成交 0 件」，物品仍在集市。陈同学这笔总价 10 元，王同学这笔总价 5 元。
4. 确认陈同学交接完成后，显示「剩余 2 件 · 已预定 1 件 · 已成交 2 件」；取消王同学的预定则恢复为剩余 3 件。单价协商仅影响对应意向的总价，申请数量保持原值。

### 多人意向演示

1. 集市搜索「多人意向演示」，选中「【多人意向演示】校园自行车」，可看到 3 人意向，售价 260 元，地点为「南湖校区 · 校门口」。提交意向只表示感兴趣，发布人接受后才预定成功。
2. 切换为**林同学**，打开「我的流转 → 想卖」，点击自行车分组展开陈、王、周三条待处理记录。选择不同记录，可分别查看或回复沟通内容。
3. 选中其中一人的记录并点「接受意向」，确认窗口会说明物品将被锁定、另外两人的意向将结束。确认后自行车从集市移除；切换其他身份，可查看各自意向已被拒绝及保留的沟通记录。
4. 切换到被选中的同学，展开分组并点击「取消预定」，自行车重新上架。切换到另外两位同学，可在「消息提醒」看到重新上架通知，点击「查看物品」后重新申请；原来的记录继续保留。也可以由林同学确认交接完成，继续演示互评。

以上是本机角色切换演示。每个身份只能查看自己参与的流转，样例地点用于演示；重启不会自动恢复这三条初始待处理意向。

身份下拉框用于现场切换角色。正式注册与登录、收藏、管理后台和统计报表留在后续迭代。GitHub Actions 使用临时 SQLite 数据库验证流转、互评和重启后的数据持久化。

## 项目结构

```text
src/main/java/edu/campus/circulation/
  App.java                 Swing 入口
  domain/                  业务实体与状态
  repository/              数据访问接口与 JDBC 实现
  service/                 业务流程、权限及事务边界
  ui/                      Swing 视图与交互
src/main/resources/        配置与运行时资源
src/test/java/             JUnit 测试
database/                  数据库初始化与迁移脚本
docs/                      需求、架构、计划、测试及重构记录
reports/                   实验报告、演示与交付材料
.github/workflows/         自动构建配置
```
