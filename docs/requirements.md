# 实验要求与交付清单

本清单整理自《2026软件构造分组实验v3》中的课程要求。当前所有待办均未验收；初始化工程不等于实现了相关功能。Java 17、包结构及具体设计模式选型为本仓库的起步方案，并非文档指定版本或方案。

## 必须满足的约束

- [ ] Java 桌面应用，Swing / WindowsBuilder 事件驱动 GUI。
- [ ] SQLite + JDBC 持久化全部业务数据，包含事务处理。
- [ ] Maven 完整源码工程，可独立部署运行的可执行 Jar。
- [ ] 3 人协作、8 周增量开发，每 2 周输出版本。
- [ ] UML 类图和时序图，与最终代码对应。
- [ ] JUnit 单元测试、集成测试、回归测试、代码走查及静态分析。
- [ ] 恰当使用至少 3 种设计模式，说明解决的问题。
- [ ] 留存函数级和类级重构的前后对比与验证记录。
- [ ] 体现防御性编程、异常处理、日志、可维护性和可扩展性。
- [ ] 覆盖模块化、面向对象、文件 IO / CSV、GUI、数据库、复用、测试、重构与交付等课程章节；不能只完成简单 CRUD。

## 核心功能

| 模块 | 验收范围 |
| --- | --- |
| 账号与权限 | 注册、登录、安全存储密码、普通学生 / 管理员角色、输入合法性校验 |
| 物品管理 | 名称、分类、描述、交换意向 / 售价、状态、标签；修改和下架自己的物品 |
| 检索与收藏 | 分类、关键词、价格区间筛选，模糊查询、列表展示、收藏 |
| 沟通与流转 | 发起意向沟通、生成流转记录、成交 / 交换状态、历史持久化 |
| 评价与信用 | 完成流转后双方互评、维护和展示信用分数 |
| 统计与导出 | 分类流转数量、低碳减排估算、统计报表、CSV 导出 |
| 管理员后台 | 用户管理、违规物品下架、类别维护、平台流转统计 |
| 图形界面 | 菜单、弹窗、表格、事件响应，以及完整业务流程操作 |

低碳减排估算需要说明计算规则、数据依据及局限，不能把估算当作实测值。信用算法、交换规则、沟通方式等细节需在需求设计阶段补充。

## 可选扩展

- [ ] 本地备份与恢复。
- [ ] 关键操作日志增强。
- [ ] 复用开源库，支持本地图片存储。
- [ ] 改善交互体验。
- [ ] 基于浏览与购买 / 交换历史的简单推荐。

总体要求已包含日志与异常处理，选做“关键操作日志”不意味着可以省略基础日志。

## 最终交付

- [ ] 课程设计报告：概述、需求、UML、模块化、数据库、关键技术、设计模式、重构、测试分析。
- [ ] 完整 Maven 源码工程和 JUnit 用例。
- [ ] SQLite 初始化脚本。
- [ ] 可直接部署运行的 Jar 包。
- [ ] 部署与使用说明书。
- [ ] 小组工作记录、分工说明、真实提交截图与次数统计。
- [ ] 演示 PPT 和软件运行视频。
