# 测试计划

当前未编写业务测试。Maven 已配置 JUnit 5 和 Surefire，GitHub Actions 执行 `mvn clean verify`，目前仅能验证工程编译和打包。

| 层次 | 后续重点 |
| --- | --- |
| 单元测试 | 非法输入、角色与所有权、物品筛选、状态变更、互评限制、信用与减排算法、CSV 转义 |
| 数据集成测试 | 临时 SQLite 数据库初始化、外键和唯一约束、事务回滚、关闭重开后的持久化 |
| 业务集成测试 | 注册 → 发布 → 检索 → 意向 → 流转完成 → 互评 → 统计 / 导出 |
| GUI 人工验证 | 菜单、表格、弹窗、异常提示、后台任务、中文显示、窗口退出 |
| 交付验证 | 干净环境运行可执行 Jar，首次初始化，读写权限错误，数据备份恢复（若实现） |
| 静态分析与走查 | SQL 注入风险、资源释放、异常吞噬、重复代码、过长方法、UI 线程阻塞 |

测试使用隔离的临时数据，不能修改成员的真实数据库。重构前保留关键行为测试，重构后运行回归测试。静态分析工具尚未接入，应在迭代中选用并记录结果。

## 测试记录模板

用例编号、目标 / 前置条件、输入与步骤、预期结果、实际结果、执行环境、关联提交、问题与修复记录。
