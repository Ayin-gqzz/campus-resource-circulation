# 三人分工与周会记录

成员姓名和账号待填写。分工可轮换，每人均需编码、测试、参与代码走查。

| 角色 | 成员 / GitHub 账号 | 主责范围 | 测试责任 |
| --- | --- | --- | --- |
| 系统设计与数据层 | 待填写 | 需求、UML、表结构、JDBC、持久化、异常与事务 | 数据约束、事务回滚、持久化集成测试 |
| 业务逻辑与测试 | 待填写 | 用户、物品、流转、评价、统计、校验、重构 | 核心业务单元测试、边界及权限测试 |
| GUI 与交付 | 待填写 | Swing、事件处理、模块组装、设计模式、Maven、发布和演示 | 界面流程、打包启动、部署验证 |

## 周会记录模板

- 日期与参会人员：待填写。
- 本周完成：附真实提交或 PR 链接。
- 问题与决策：记录接口、业务规则及设计调整。
- 走查与测试：记录发现的问题和对应修复。
- 下周任务：任务、负责人、验收条件。

提交统计可用 `git shortlog -sne --all` 辅助获取。统计口径和账号对应关系应说明清楚，提交次数不能单独代表贡献。
